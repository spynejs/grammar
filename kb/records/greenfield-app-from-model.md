### greenfield-app-from-model
`record:greenfield-app-from-model` · scaffold

**Recognize when:** "build me a site/app with these pages" — a whole application described as content and structure, not components.

The greenfield master record, and app-builder tier of the product: request/config (Stage 0) → one generative act emits a complete, schema-validated app model — pages, heroes, subpages, pageItems composed from a component catalog, text content, image search intents (Stage 1) → deterministic assembly: validate, resolve images, inject model into cloned canonical scaffold, package (Stage 2). Zero code is generated; routes, nav, breadcrumbs, and page swapping all derive from the one data artifact via the homology machinery.

**Composes:** op:author-app-model-node, op:author-pageitem-spec, op:prototype-in-data-then-promote, op:images-by-search-intent-not-url, op:attr-prefix-for-attribute-placeholders, op:name-route-keys-for-legibility, op:design-route-config-tree
